HTML·Bootstrap·JavaScript 실습 페이지입니다. 파일 번호는 작성한 순서이고, 브라우저로 열면 바로 볼 수 있습니다.
수업 실습에 쓰는 이미지는 `lectures/images/`에 있으며 HTML에서 상대 경로(`images/…`)로 불러옵니다.

```
HTML/
├── lectures/          # 수업 실습 (01~08 HTML·Bootstrap, 09~19 JavaScript)
│   └── images/        # 실습에 쓰는 이미지
└── project/           # 개인 프로젝트
```
